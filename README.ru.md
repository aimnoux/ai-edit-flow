# ai-edit-flow

[English](README.md) · **Русский**

Стартовый набор для монтажа видео с Claude Code. Ты записываешь, Claude монтирует: режет дубли и паузы, чистит голос, рисует графику кодом, проверяет кадры, сводит звук и рендерит готовый файл. Таймлайн открывать не нужно.

## Что это

Скелет монтажного пайплайна, который агент проходит сам от начала до конца. Это набор скиллов и скриптов для Claude Code, от сырой записи до готового видео:

- **Нарезка** — убрать плохие дубли, паузы и мусор из записи
- **Голос** — чистка и, если хочешь, клон твоего голоса для переписанных фраз
- **Графика** — титры, схемы и переходы написаны кодом, а не накликаны
- **Ревью** — второй агент проверяет выборку кадров и переходы между сценами по чек-листу, прежде чем ты увидишь результат
- **Звук** — музыка, эффекты и сведение
- **Рендер** — готовый файл для загрузки

Два формата: горизонтальное видео (16:9) и вертикальное (9:16, одна сборка для Shorts, Reels и TikTok; концовка под площадку — параметр, а не ветка кода).

Визуального стиля внутри нет. Набор даёт костяк, свой вид ты наращиваешь с Claude сессия за сессией. Отдельный скилл расспрашивает тебя и пишет файл твоего стиля.

## Чем это не является

Не видеоредактор и не плагин к нему. Не модель, не сервис, аккаунт не нужен. Это репозиторий, который ты открываешь в Claude Code и с которым разговариваешь.

## Установка

Нужны: [Claude Code](https://claude.com/claude-code), git, Python 3.10+, Node.js 22+ и ffmpeg (включая ffprobe). Для рендера setup скачивает отдельный `chrome-headless-shell`; личный Google Chrome не используется. Ключ [ElevenLabs](https://elevenlabs.io) необязателен: на нём работают распознавание речи для нарезки, клон голоса и музыка.

```bash
git clone https://github.com/aimnoux/ai-edit-flow.git
cd ai-edit-flow
bash setup.sh
source .venv/bin/activate
```

`setup.sh` проверяет инструменты, создаёт локальную `.venv` (или использует уже активированное виртуальное окружение Python), ставит пакеты туда, создаёт `.env` из `.env.example` и скачивает отдельный браузер командой `node engine/hf.mjs browser ensure`. Если обязательный шаг не прошёл, скрипт завершается с ошибкой. Глобально пакеты Python не ставятся, рендер не запускается. Если есть ключ ElevenLabs, впиши его в `.env`. Дальше открой папку в Claude Code и скажи, что нужно: «собери мой стиль», «вот запись, нарежь», «сделай вертикалку по этому тексту».

Перед запуском Python-скриптов и Claude Code из терминала активируй окружение: дочерние команды получают его `PATH`. На Windows в Git Bash: `source .venv/Scripts/activate`. Если использовал своё окружение, оставь активным его. Для рендера ключ ElevenLabs не нужен; распознавание речи, клон и генерация музыки обращаются к платному API, когда ты их запрашиваешь.

Набор собирался на macOS. Адаптации под Linux и Windows полностью не проверены; на Windows нужны Git Bash, обычные Python/Node.js и ffmpeg в `PATH`. Автозагрузка закреплённого браузера не поддерживает Linux ARM64: укажи совместимый отдельный `chrome-headless-shell` через `CHROME_PATH` в `.env`; setup не ставит системный Chromium. На старых системах тоже может понадобиться совместимая версия shell.

Браузер ищется сначала по `CHROME_PATH`, затем в кэше HyperFrames (`~/.cache/hyperframes/chrome/chrome-headless-shell/`) и в кэше headless-shell Puppeteer (`PUPPETEER_CACHE_DIR` или `~/.cache/puppeteer`). Принимается только исполняемый файл `chrome-headless-shell`, в том числе после раскрытия симлинков. Обычный Chrome и настольный Chrome for Testing не используются. Команда создаёт временный отдельный профиль и убирает свой браузер после работы; фоновое ожидание команд HyperFrames отключено.

## Запись и формат сценария

Живая запись может быть аудио или видео. Нарезка пишет `voice.wav` для аудиозаписи и `rough.mp4` для видео, а также `words.json` и `edl.json`. Для длинного видео дальше добавляются паузы между главами; вертикалка принимает папку нарезки напрямую: `vertical.py build ... --cut <dir>`.

Речь находится под заголовками `### N.M`. Абзацы разделяются пустой строкой; перенос одного абзаца на несколько строк исходника не добавляет паузу. Заметки с `> `, таблицы и заголовки не озвучиваются. В пачке вертикалок `N.0` — отбивка для записи, `N.8` — концовка YouTube, `N.9` — концовка Instagram/TikTok.

## Что внутри

```
.claude/skills/    девять скиллов: edit, cut, voice, graphics, vertical, review, sound, render, style
engine/            скрипты (Python, Node) и маленькая библиотека для композиций, без стиля
style/             твой стиль: шаблоны, которые нужно заполнить
videos/<slug>/     горизонтальное видео: сценарий, настройки; записи и голос не в git
vertical/          вертикалки: один текстовый файл на пачку
CLAUDE.md          как агент работает с тобой
```

Графика рендерится через [HyperFrames](https://hyperframes.heygen.com) (композиции HTML + GSAP), версия закреплена одна на весь репозиторий в `package.json`.
