# ai-edit-flow

[English](README.md) · **Русский**

Стартовый набор для монтажа видео с Codex или Claude Code. Ты записываешь, агент монтирует: режет дубли и паузы, чистит голос, рисует графику кодом, проверяет кадры, сводит звук и рендерит готовый файл. Таймлайн открывать не нужно.

## Что это

Скелет монтажного пайплайна, который агент проходит сам от начала до конца. Это набор скиллов и скриптов для Codex и Claude Code, от сырой записи до готового видео:

- **Нарезка** — убрать плохие дубли, паузы и мусор из записи
- **Голос** — чистка и, если хочешь, клон твоего голоса для переписанных фраз; два голоса с тегами интонаций для скетча
- **Графика** — титры, схемы и переходы написаны кодом, а не накликаны
- **3D и шейдеры** — сцены three.js и миры на чистом WebGL со смазом, глубиной резкости и мягкими тенями (нужна видеокарта)
- **Ревью** — второй агент проверяет выборку кадров и переходы между сценами по чек-листу, прежде чем ты увидишь результат
- **Звук** — музыка, эффекты и сведение
- **Рендер** — готовый файл для загрузки

Два формата: горизонтальное видео (16:9) и вертикальное (9:16, одна сборка для Shorts, Reels и TikTok; концовка под площадку — параметр, а не ветка кода).

Визуального стиля внутри нет. Набор даёт костяк, свой вид ты наращиваешь с агентом сессия за сессией. Отдельный скилл расспрашивает тебя и пишет файл твоего стиля.

## Чем это не является

Не видеоредактор и не плагин к нему. Не модель, не сервис, аккаунт не нужен. Это репозиторий, который ты открываешь в Codex или Claude Code и с которым разговариваешь.

## Установка

Нужны: Codex или [Claude Code](https://claude.com/claude-code), git, Python 3.11–3.13, Node.js 22.12+ и ffmpeg (включая ffprobe). Для рендера setup скачивает отдельный `chrome-headless-shell`; личный Google Chrome не используется. Ключ [ElevenLabs](https://elevenlabs.io) необязателен: на нём работают распознавание речи для нарезки, клон голоса и музыка.

```bash
git clone https://github.com/aimnoux/ai-edit-flow.git
cd ai-edit-flow
bash setup.sh
source .venv/bin/activate
```

`setup.sh` проверяет инструменты, создаёт локальную `.venv` (или использует уже активированное виртуальное окружение Python), ставит пакеты туда, создаёт `.env` из `.env.example`, ставит JavaScript-зависимости через `npm ci` по `package-lock.json`, проверяет копии скиллов, загружает закреплённый GSAP и скачивает отдельный браузер командой `node engine/hf.mjs browser ensure`. Если обязательный шаг не прошёл, скрипт завершается с ошибкой. Глобально пакеты Python не ставятся, рендер не запускается. Если есть ключ ElevenLabs, впиши его в `.env`. Дальше открой папку в Codex или Claude Code и скажи, что нужно: «собери мой стиль», «вот запись, нарежь», «сделай вертикалку по этому тексту».

Перед запуском Python-скриптов и агента из терминала активируй окружение: дочерние команды получают его `PATH`. На Windows в Git Bash: `source .venv/Scripts/activate`. Если использовал своё окружение, оставь активным его. Для рендера ключ ElevenLabs не нужен; распознавание речи, клон и генерация музыки обращаются к платному API, когда ты их запрашиваешь.

Набор собирался на macOS. Адаптации под Linux и Windows полностью не проверены; на Windows нужны Git Bash, обычные Python/Node.js и ffmpeg в `PATH`. Автозагрузка закреплённого браузера не поддерживает Linux ARM64: укажи совместимый отдельный `chrome-headless-shell` через `CHROME_PATH` в `.env`; setup не ставит системный Chromium. На старых системах тоже может понадобиться совместимая версия shell.

Браузер ищется сначала по `CHROME_PATH`, затем в кэше HyperFrames (`~/.cache/hyperframes/chrome/chrome-headless-shell/`) и в кэше headless-shell Puppeteer (`PUPPETEER_CACHE_DIR` или `~/.cache/puppeteer`). Принимается только исполняемый файл `chrome-headless-shell`, в том числе после раскрытия симлинков. Обычный Chrome и настольный Chrome for Testing не используются. Команда создаёт временный отдельный профиль и убирает свой браузер после работы; фоновое ожидание команд HyperFrames отключено.

## Запись и формат сценария

Живая запись может быть аудио или видео. Нарезка пишет `voice.wav` для аудиозаписи и `rough.mp4` для видео, а также `words.json` и `edl.json`. Для длинного видео дальше добавляются паузы между главами; вертикалка принимает папку нарезки напрямую: `vertical.py build ... --cut <dir>`.

Речь находится под заголовками `### N.M`. Абзацы разделяются пустой строкой; перенос одного абзаца на несколько строк исходника не добавляет паузу. Заметки с `> `, таблицы и заголовки не озвучиваются. В пачке вертикалок `N.0` — отбивка для записи, `N.8` — концовка YouTube, `N.9` — концовка Instagram/TikTok.

## Что внутри

```
.agents/skills/    основные скиллы: edit, cut, voice, graphics, 3d, vertical, review, sound, render, style
engine/            скрипты (Python, Node) и маленькая библиотека для композиций, без стиля
style/             твой стиль: шаблоны, которые нужно заполнить
videos/<slug>/     горизонтальное видео: сценарий, настройки; записи и голос не в git
vertical/          вертикалки: один текстовый файл на пачку
AGENTS.md          общие инструкции для обоих агентов
CLAUDE.md          короткая точка входа; .claude/skills/ — сгенерированная копия
```

Графика рендерится через [HyperFrames](https://hyperframes.heygen.com) (композиции HTML + GSAP), версия закреплена одна на весь репозиторий в `package.json`.

## 3D и шейдеры

| Задача | Скилл | Чем рисуем | Рендер |
|---|---|---|---|
| Вещи, персонажи, комнаты; скетч 9:16 с двумя голосами | `3d`, `voice`, `vertical` | three.js r181 (лежит в наборе, MIT) | `engine/render3d.mjs` |
| Мир, написанный фрагментным шейдером, по ударам трека | `3d` | WebGL2 | `engine/render3d.mjs` |

**Нужна видеокарта.** Проверено на macOS с Metal, на Windows и Linux не проверялось. `node engine/render3d.mjs --doctor` покажет, что
получает браузер, а без видеокарты рендер остановится с понятным сообщением. Примеры без платных запросов:

```
python engine/vertical.py build vertical/sketch.md 1 yt --estimate
node engine/render3d.mjs sketch-s1-yt --draft
node engine/render3d.mjs scenes/shader-example/index.html --draft
```

## Бесплатный локальный пример

После установки запусти `python engine/demo.py`. Команда берёт существующую вертикалку example,
локально создаёт звуковые тоны и точные тайминги слов, затем рендерит черновик 10 fps одним
воркером отдельного браузера. Результат: `engine/renders/demo/demo.mp4`; лог: `engine/build/demo/`.
Обращений к ИИ, ElevenLabs и платным сервисам нет. Тоны — тестовый звук, не речь.
`--prepare-only` собирает звук, тайминги и HTML без браузера; для первых загрузок зависимостей,
браузера и GSAP при установке нужна сеть. Пример использует нейтральный шаблон и не выбирает твой стиль.

## Инструкции и локальные проверки

Источники инструкций — только `AGENTS.md` и `.agents/skills/`. После правки скилла запусти
`python engine/sync_skills.py`: он создаёт обычные файлы в `.claude/skills/` вместе со справочниками,
без симлинков. `python engine/sync_skills.py --check` проверяет расхождения без записи файлов.
Загружается только нужный скилл; полный чек-лист с 65 кодами читает отдельно ревьюер.

`python -m unittest discover -s tests -v` проверяет синтетические медиа и подменённые границы API/браузера.
`python engine/contracts.py --json` выдаёт детерминированные проверки разбора сценария, триггеров,
длины звуковой огибающей и привязки ревью к отпечатку входов. Соседний репозиторий, ключи и живые
сервисы не нужны. Python-пакеты закреплены в `requirements.txt`, Node-зависимости и их контрольные
суммы — в `package-lock.json`. Обновляй их вместе с регрессионными проверками. Поддерживаемый
диапазон Python — 3.11–3.13; полный локальный пример проверен на Python 3.13/macOS.

## Одна команда проверки

`python engine/verify.py <id-композиции>` проверяет выполнение сцен и HyperFrames, готовит листы
кадров для ревью (`--project <slug>` проверяет проект; `--video out.mp4` добавляет проверку рендера).
Без изменений используются готовые листы и записанное заключение ревьюера: меньше запусков браузера
и повторных снимков. Изменения сбрасывают кэш. Успех автоматических проверок требует отдельного
визуального заключения перед показом; `--force` запускает свежую проверку.
